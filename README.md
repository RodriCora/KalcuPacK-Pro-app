# 📦 KalcuPacK Pro

**KalcuPacK Pro** es una aplicación web diseñada para agilizar el cálculo de liquidaciones diarias de repartos logísticos.

### 🚀 Funcionalidades
* **Cálculo por Zonas:** Diferenciación de tarifas entre Zona A y Zona B.
* **Gestión Automática:** El valor de las gestiones se vincula automáticamente al precio del paquete de la zona seleccionada.
* **Contadores Dinámicos:** Interfaz optimizada para uso en dispositivos móviles.
* **Historial Local:** Guarda el registro de los repartos en la memoria del navegador.
* **Exportación PDF:** Genera reportes detallados para rendición de cuentas.

### 🛠️ Configuración
La aplicación cuenta con una sección protegida por PIN para ajustar los valores de los servicios (Paquetes, Retiros, Tarjetas, Movistar).
